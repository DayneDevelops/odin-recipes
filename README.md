# odin-recipes
This is my first HTML project as part of The Odin Project foundations course.

The goal of this project is to build a basic recipe website that contains a homepage and links to individual recipe pages. 

Skills Demonstrated

Creating HTML boilerplate.

Using headings, paragraphs, and lists.

Adding images to webpages.

Creating links between multiple webpages.

Organizing files and directories.

Using Git and GitHub to track and manage my project.
